# PAS Framework

**Type:** Framework Note  
**Links:** [[Copywriting Fundamentals]] · [[AIDA Framework]] · [[Hook Writing]] · [[CTA Writing]] · [[Performance Ads]] · [[Audience Targeting]]

---

## Core Idea

PAS is a lean, high-converting copywriting framework built around the reader's pain. It's especially effective when the audience is already aware of a problem and just needs someone to name it clearly.

**P — Problem → A — Agitate → S — Solution**

---

## Breakdown

### P — Problem
State the problem the reader has. Be specific and direct — they should feel seen.

> *"Your ads are getting clicks but no conversions."*

### A — Agitate
Twist the knife (kindly). Make the problem feel urgent, costly, or frustrating.

> *"Every day you're running those ads, you're burning budget on people who bounce before they ever see the offer. That's compounding — the longer it runs, the worse the data gets."*

### S — Solution
Introduce the product/service as the clear resolution to the pain.

> *"[Product] analyses your copy against 10,000 high-converting variants and tells you exactly what to change — in 60 seconds."*

---

## When to Use PAS

- Short-form ads (Google Search, Instagram Stories, Twitter)
- Pain-aware audiences (they know the problem, don't need educating)
- Direct response contexts where speed matters
- Cold outreach where you need to qualify fast

---

## PAS Variants

| Variant | Structure | Best For |
|---|---|---|
| Core PAS | Problem → Agitate → Solution | Short ads, outreach |
| PASO | Problem → Agitate → Solution → Outcome | Slightly longer, outcome-led |
| BAB | Before → After → Bridge | Transformation stories |
