# Ad Format Library

**Type:** Platform Note  
**Links:** [[Platform Overview]] · [[Performance Ads]] · [[Organic Ads]] · [[Copy Testing & Iteration]]

---

## Core Idea

Different ad formats have different copy constraints. The platform needs to know the rules of each format to generate copy that actually fits.

---

## Meta Ads

| Format | Headline Limit | Body Limit | Notes |
|---|---|---|---|
| Feed (Single Image) | 40 chars | 125 chars (before truncation) | Most flexible format |
| Stories / Reels | Overlay text only | ~30 chars visible | Visual-first; copy minimal |
| Carousel | 40 chars per card | 125 chars shared body | Each card needs its own hook |
| Collection | 40 chars | 125 chars | Product catalogue driven |

---

## Google Ads

| Format | Constraints | Notes |
|---|---|---|
| Responsive Search Ad | 15 headlines (30 chars each), 4 descriptions (90 chars) | Google mixes and matches — each headline must stand alone |
| Display / Responsive Display | Short headline: 25 chars, Long headline: 90 chars | Image-led; copy secondary |
| Performance Max | All of the above | Omnichannel — copy must work across contexts |

---

## TikTok Ads

| Format | Constraints | Notes |
|---|---|---|
| In-Feed Ad | Caption: 100 chars | First 3 seconds of video = the hook |
| TopView | 80-char text overlay | Premium placement — must be visually arresting |
| Branded Hashtag | Hashtag prompt + 150-char description | Community/UGC mechanic |

---

## LinkedIn Ads

| Format | Constraints | Notes |
|---|---|---|
| Sponsored Content | Headline: 70 chars, Intro: 150 chars | Professional tone required |
| Message Ad | Subject: 60 chars, Body: 1500 chars | Conversational, not salesy |
| Text Ad | 25-char headline, 75-char body | Minimal — specificity critical |

---

## Email

| Element | Best Practice |
|---|---|
| Subject Line | 6–9 words, curiosity or benefit led |
| Preview Text | 40–90 chars, adds context to subject |
| Body | Hook → Value → CTA structure |
| CTA Button | 2–5 words, benefit-led verb |
