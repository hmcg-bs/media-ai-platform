# 2026-05-27 — Project scaffold and structure design

## Goal
Design and scaffold the full Media AI Platform project structure: directory layout, CLAUDE.md instructions, environment variables, and Obsidian vault reorganization with clear separation between architectural reference (Structure/) and work logs (Sessions/).

## Decisions Made
- **Tech Stack:** Python 3.12 + FastAPI (backend), Next.js 14 (frontend), LiteLLM (multi-model abstraction), Supabase (PostgreSQL + pgvector)
- **Multi-model support:** Route copy generation to Claude, vision tasks to GPT-4o, maintain open-source fallback via Ollama/Replicate
- **Vault organization:** Split into two folders — Structure/ (static ADRs, conventions, schemas) and Sessions/ (dynamic daily notes, changelog, git log)
- **Session logging:** After every Claude session, write to Daily/YYYY-MM-DD.md, append to Changelog.md for features, append to Git-Log.md for commits
